**Number Guessing Game (C Program)**
A fun and interactive Number Guessing Game written in C.
This version includes:
Difficulty levels:-
-->Play again option
-->Random number generation
-->Attempt counter

Perfect beginner-friendly project for practicing C programming and uploading on GitHub.

**How the Game Works**
1.Player selects a difficulty level.
2.Computer picks a random number in the chosen range.
3.Player keeps guessing until they find the correct number.
4.After each guess, the game gives hints:
"Too High!"
"Too Low!"
5.Game shows total attempts.

6.Player decides whether to play again or exit.

**Requirements**
1.C compiler (GCC recommended)
2.VS Code / CodeBlocks / Turbo C / any C IDE
3.Basic understanding of input-output in C
